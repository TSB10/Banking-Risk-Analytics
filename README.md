# Banking Risk Analytics | SQL • Python • Power BI

## Project Overview
An end-to-end Banking Risk Analytics project analyzing customer behaviour, credit risk, loan portfolio performance, and banking transactions using SQL, Python, and Power BI.

The project analyzes **5,000 customers, 6,500 loans, and 30,000 transactions** to identify financial risk patterns and support data-driven banking decisions.

## Tools & Technologies
- **SQL (MySQL):** Joins, aggregations, CTEs, conditional statements, and window functions.
- **Python:** Pandas, NumPy, Matplotlib, and Seaborn for data cleaning and exploratory data analysis.
- **Power BI:** Data modeling, DAX measures, interactive dashboards, KPIs, and slicers.
- **Jupyter Notebook:** Data exploration and visualization.

## Key Business Insights
- **Loan Risk:** Education Loans recorded the highest default rate at 10.20%.
- **Credit Exposure:** Personal Loans contributed the largest principal amount associated with defaulted loans, approximately ₹19.80 crore.
- **Customer Segmentation:** Mass Market customers represented 62.42% of the customer base.
- **Transaction Performance:** The transaction failure rate was 3.55%, highlighting an area for operational investigation.
- **Risk Monitoring:** SQL analysis identified opportunities to prioritize customers based on outstanding exposure.

## Power BI Dashboard
Developed three interactive dashboard pages:

1. **Executive Overview:** Customer segments, loan KPIs, and portfolio performance.
2. **Credit & Loan Risk Analysis:** Outstanding balances, credit risk, and loan exposure.
3. **Transaction Analysis:** Transaction performance, channel analysis, and failure rates.

## Business Recommendations
- Monitor loan defaults by product and customer segment.
- Investigate high-risk loan exposures.
- Analyze transaction failures across channels.
- Improve credit-risk monitoring and reporting.
- Use interactive dashboards for data-driven decision-making.

## Project Outcome
Demonstrated an end-to-end data analytics workflow, combining SQL analysis, Python-based EDA, and Power BI reporting to transform banking data into actionable business insights.

*Portfolio case study based on supplied project data; not a predictive credit-risk model.*
